# Legacy TSP scripts

These scripts are preserved for reproducibility and development history, but they are **not** the authoritative entry points for the current TSP study.

Use:

- `../../realnvp_tsp_baseline_v1.py` for the frozen RealNVP baseline;
- `../../baselines/inversion_baseline_10seeds.py` for the classical inversion reference;
- `../../diagnostics/MODE_COLLAPSE_ANALYSIS_2026-09-23.md` for the mode-collapse investigation.

The files in this directory represent earlier single-run, multi-seed, or sanity-check entry points that were useful during development.
